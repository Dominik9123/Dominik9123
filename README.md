## Featured Projects

### 🔐 [Password Security Analyzer API](https://github.com/Dominik9123/password-security-analyzer-api)
**Python · FastAPI · Pytest · Docker · GitHub Actions**

A REST API for evaluating password strength and identifying common weaknesses.

- Estimates password entropy and provides strength assessments.
- Checks passwords against common weak-password patterns.
- Includes automated tests with **Pytest**, containerization with **Docker**, and a **GitHub Actions** workflow.

### 💰 [Personal Finance Tracker](https://github.com/Dominik9123/financev2)
**C# · ASP.NET Core · Entity Framework Core · SQLite · React**

A full-stack application for managing personal finances, combining a REST API, relational database, and web interface.

- Built backend endpoints for financial data and transaction management.
- Used **Entity Framework Core** and **SQLite** for data persistence.
- Added financial data visualization and integration with the **National Bank of Poland API** for exchange rates.
